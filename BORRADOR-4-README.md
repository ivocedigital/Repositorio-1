# Borrador 4 — fotografías originales

Video vertical de 30 segundos (1080×1920). Usa las fotografías originales de Simmons, Vortex y Leica incluidas por el usuario en `Binocualres.zip`. Conserva el ajuste de textos y los whooshes suaves del borrador 3.

La imagen del ZIP llamada `03-compacto.png` es un Vanguard ED 8×42. Dado que el usuario pidió mantener «Compacto», el borrador usa una tarjeta gráfica para esta necesidad hasta recibir una fotografía correcta o confirmar que se deje sin foto. El archivo recibido se conserva en la carpeta de recursos como `03-vanguard-ed-8x42.png` y no aparece en el video.
