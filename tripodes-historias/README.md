# Historias Vanguard

Cuatro videos verticales independientes para Instagram Stories, 1080 × 1920, 15 segundos cada uno. Sin voz, música ni efectos; usan fotografías de producto proporcionadas por el usuario y tipografía Montserrat. No incluyen logo de MonteAdentro. La historia 3 reserva espacio inferior para un sticker nativo de Instagram.

La historia 2 presenta únicamente los modelos confirmados como disponibles: ALTA PRO 3VL 303AV18, VEO 2 PRO 263AV, VEO 3T+ 264CB y VEO 3 263AB. La historia 4 muestra únicamente equipos de esa lista. No se indican cantidades porque la actualización de disponibilidad no las confirma.

Cada MP4 usa H.264/yuv420p, dura 15 segundos, no contiene pista de audio y tiene el índice del archivo al inicio para facilitar reproducción web. `historias-tripodes-vanguard.zip` agrupa los cuatro archivos.
